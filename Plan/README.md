Point de départ comparé : [Family Tree Easy](https://familytreeeasy.com/fr/builder), qui aligne des personnes mais ne structure pas les foyers polygames et laisse les liens de cousins se confondre avec ceux des fils.

Décisions déjà prises : rail adaptatif selon le nombre d’épouses, rang d’union conservé pour une analyse ultérieure, une seule carte si deux cousins se marient, plusieurs vues conservées. La saisie se fait dans l’atelier `/quick-start`, foyer par foyer.
